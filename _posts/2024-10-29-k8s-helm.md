[Helm](https://helm.sh/docs/intro/install/) is distributed as a single binary. Installing it from the release tarball lets you pin an exact version. Pick a version from the [Helm releases page](https://github.com/helm/helm/releases). This example uses 3.16.2 on `amd64`:

```shell
HELM_VERSION=v3.16.2
wget https://get.helm.sh/helm-${HELM_VERSION}-linux-amd64.tar.gz
tar -zxvf helm-${HELM_VERSION}-linux-amd64.tar.gz
sudo install linux-amd64/helm /usr/local/bin/helm
```

Verify the installation:

```shell
helm version
```

On ARM machines, replace `linux-amd64` with `linux-arm64`.
